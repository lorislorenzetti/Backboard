How to Change Your Rocket League Name Without Cooldown

Rocket League ties your display name to your Epic Games account — and Epic limits how often you can rename it. If you have hit the cooldown or just want a different name for tonight's session, Bakkboard's Fake Name feature lets you set any display name instantly, with no waiting period.

Why you can't rename freely in Rocket League

On Steam and Epic Games, your Rocket League display name comes from your platform account. Epic Games enforces a rename cooldown — after you change your Epic display name, you typically have to wait before you can change it again. That cooldown applies even if you only want a temporary joke name for one night of ranked.

There is no in-game setting to bypass this. The only official path is waiting out the cooldown or using a different account.

Change your name anytime with Bakkboard

Bakkboard's Fake Name feature sets a custom display name that Rocket League shows in lobby and in matches. Key points:

  • Any name you want — set whatever display text you like.
  • No Epic cooldown — change it whenever you want, as many times as you want.
  • Visible in lobby — other players see your fake name, not your real Epic display name.

This is useful if you want a fresh identity for a stream, a themed session with friends, or simply to avoid burning your official Epic rename on something temporary.

How to set it up

  1. Open Bakkboard and go to the Spoofing tab.
  2. Select the Name section.
  3. Type your desired display name.
  4. Enable the feature — your new name appears the next time you enter a lobby.

To revert, disable Fake Name or clear the field. Your real Epic display name shows again.

Fake Name vs. an official Epic rename

An official Epic rename changes your account name everywhere Epic recognizes it — friends lists, other games, and permanently until you rename again (subject to cooldown). Bakkboard's Fake Name only affects what Rocket League displays in-session and in lobby while the feature is active. It does not change your Epic account or consume a rename slot.

If you need a permanent name change across Epic, you still need to use Epic's account settings. If you need flexibility without cooldown, Fake Name is the answer.

Does it affect matchmaking or bans?

Bakkboard does not inject into the game process or modify memory. Fake Name works through the same safe approach as other Bakkboard features — outside the game process, with no interaction with Easy Anti-Cheat. There is no ban risk from using Bakkboard for display name changes.
